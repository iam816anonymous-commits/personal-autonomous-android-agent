# Research and engineering knowledge base

Single home for project research and non-executable engineering documentation.

- [RESEARCH](RESEARCH/README.md) — platform constraints, repository deep dives, model/inference research, policy and source reuse.
- [ARCHITECTURE](ARCHITECTURE/) — execution, safety, memory, device control and model routing.
- [DESIGN](DESIGN/) — integrated full-agent design.
- [ENGINEERING](ENGINEERING/) — contracts, data model, budgets, test strategy and Argon donor-validation archive.
- [ROADMAP](ROADMAP/) — phases, implementation blueprint and acceptance criteria.
- [REFERENCES](REFERENCES/) — primary sources and citations.
- [IMPLEMENTATION](IMPLEMENTATION/) — implementation tranche notes and porting review. Actual source code is in [agent/](../agent/).

The root [PROJECT_STATUS.md](../PROJECT_STATUS.md) is the canonical live status. This folder contains research and design evidence, not the current implementation truth.
